PORTFOLIO — MICRO-INTERACTIONS EDITION

Cara pakai:
1. Ekstrak semua file dari ZIP ke satu folder.
2. Buka index.html di browser, atau jalankan melalui Live Server di VS Code.
3. Jaga nama CSS persis sebagai style.css, bukan style.css.css.

Yang ditambahkan:
- Reveal halus saat scroll, scroll-progress bar, active navigation, dan mobile dropdown.
- Hero cursor spotlight (desktop), animasi judul, hover card/project/services/skills.
- Hover/press/ripple tombol dan feedback toast untuk salin email.
- Modal animasi masuk/keluar, Escape untuk menutup, dukungan keyboard dan fokus.
- Adaptasi untuk preferensi reduced motion dan HP.

Catatan:
- Identitas, layout, teks, dan palet warna situs asli dipertahankan.
- Form kontak asli belum punya backend. Pada versi ini form menyiapkan draft email
  lewat aplikasi email pengguna; user tetap perlu menekan Kirim.
- URL demo proyek contoh (example.com) dan profil media sosial masih placeholder.
- Fonts dan Lucide Icons menggunakan CDN; butuh internet untuk memuatnya.
